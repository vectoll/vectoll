// 05. OPEN SPECIFICATION & CONFORMANCE

        
Built on Open RFCs, Audited for Production

        

          Every Vectoll primitive is specified in public RFCs, backed by 500-vector adversarial fuzzing and 100-way concurrent double-spend verification.
        


        

          

            
Wire Protocol & ReceiptsRFC-0001

            
Canonical HTTP 402 + x402 V2 challenge format, request-bound SHA-256 reqHash, and compact Ed25519 vrt1 receipts verifiable completely offline via did:key.

          

          

            
MCP Payment BindingRFC-0002

            
Native Model Context Protocol JSON-RPC 2.0 metering via _meta.vectoll, deterministic tool parameter hashing, and one-command vectoll mcp-bridge for Claude & Cursor.

          

          

            
Spend Mandates & PasskeysRFC-0003

            
Delegated agent budgets signed with Ed25519 (vsm1) or hardware WebAuthn FIDO2 P-256 Passkeys (vsm1p), plus Human-in-the-Loop (HITL) approval gates and escrow release/refund.

          

          

            
Cross-Facilitator FederationRFC-0004

            
Zero-lock-in peering vouchers (vfv1) allowing an agent funded on Facilitator A to settle instantly against a merchant on Facilitator B with bilateral net settlement.
