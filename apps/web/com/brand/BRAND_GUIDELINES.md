# Vectoll Brand Identity & Visual System

Vectoll's visual system derives directly from its **extruded double-line architectural block-wireframe wordmark**: stark geometric precision paired with terminal-grade telemetry clarity.

## Core Assets (`brand/`)

| File | Usage |
| :--- | :--- |
| [`brand/logo-wordmark-dark.svg`](./logo-wordmark-dark.svg) | Primary wordmark for dark UIs, headers, and developer docs |
| [`brand/logo-wordmark-light.svg`](./logo-wordmark-light.svg) | Inverted wordmark for light documentation and print |
| [`brand/logo-mark.svg`](./logo-mark.svg) | Standalone extruded geometric **V** emblem (`256×256` vector) |
| [`brand/favicon.svg`](./favicon.svg) | Crisp `64×64` browser tab & app icon |
| [`brand/readme-banner.svg`](./readme-banner.svg) | `1280×360` GitHub README hero header |
| [`brand/social-og-preview.svg`](./social-og-preview.svg) | `1200×630` OpenGraph / X / GitHub Social Preview card |

## Color Tokens

| Token | Hex | Role |
| :--- | :--- | :--- |
| **Obsidian Ground** | `#070A10` | Primary page background |
| **Carbon Surface** | `#0D1117` | Code panels, terminal cards, GitHub-native canvas |
| **Slate Wireframe** | `#1E293B` / `#64748B` | Architectural borders and extruded wireframe shadows |
| **Chalk Foreground** | `#F8FAFC` | Primary geometric letterforms and headlines |
| **Settlement Emerald** | `#10B981` | Verified `200 OK`, balanced ledger, active status node |
| **x402 Cobalt** | `#3B82F6` | Protocol headers, HTTP 402 challenges, links |
| **MCP Violet** | `#8B5CF6` | Model Context Protocol tooling & AI agent SDK badges |

## Typography

* **Display & UI:** `Inter`, system geometric sans-serif (`font-weight: 600–800`, tight `-0.03em` tracking on headings)
* **Protocol, Code & Telemetry:** `JetBrains Mono` / `ui-monospace`
