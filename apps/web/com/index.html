Frequently Asked Questions

        

          Will Vectoll slow down or paywall our human website visitors?
          
Never. Routes with browsers: 'free' allow standard interactive browsers through with zero prompts and <0.15ms overhead, while autonomous crawlers and AI SDKs receive standard HTTP 402 challenges.

        

        

          How can Vectoll process $0.001 calls without losing money to $0.30 card fees?
          
Agents maintain pre-funded multi-rail floats (or stream x402 USDC / Enterprise Vouchers) inside Vectoll's integer double-entry clearing engine. Each API call deducts exact minor units and mints an offline-verifiable Ed25519 vrt1 receipt, while bank/wallet sweeps execute in aggregated batches.

        

        

          Are we locked into Vectoll Cloud if we integrate the SDK?
          
Zero lock-in. Every middleware, receipt format (vrt1), Passkey mandate (vsm1p), and peering voucher (vfv1) is Apache 2.0 open source on vectoll.org. Switching between self-hosted and Vectoll Cloud is a 1-line facilitatorUrl change.
